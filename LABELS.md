# Issue Labels

Labels used on issues in this repository, per the contributing conventions (English).

## Difficulty

| Label | Meaning | Color |
|-------|---------|-------|
| `difficulty:low` | Low implementation complexity | #0e8a16 |
| `difficulty:medium` | Medium implementation complexity | #fbca04 |
| `difficulty:high` | High implementation complexity | #b60205 |

## Value

| Label | Meaning | Color |
|-------|---------|-------|
| `value:low` | Low value for user/business | #d73a4a |
| `value:medium` | Medium value for user/business | #fbca04 |
| `value:high` | High value for user/business | #0e8a16 |

## Usage

Each open issue should carry one difficulty label and one value label. These are estimates by the maintainer; they are not a promise of effort or priority.
